# Settings

Open **Settings → AGLC4 Citations**. Many style settings can also be set for one note in its properties ([a note's own style](notes.md#a-notes-own-style)).

## Getting started

- **Create example essay**: adds an example essay to try the plugin on ([getting started](getting-started.md)).

## Notes

- **Use AGLC4 in**: all notes, assignment notes only (property `aglc` ticked), or assignment notes and notes in chosen folders ([notes](notes.md)).
- **Folders**: the folders whose notes the plugin works in, one per line, with "Assignment notes, and notes in these folders".

## Checking

- **Underline problems**: underline incorrect or incomplete citations as you write ([checking](checking.md)).
- **Show suggestions**: also mark lesser points with a dotted underline.
- **Disabled rules**: rule identifiers to ignore, one per line. **Ignore this rule** in the hover box adds to this list. See the [rules reference](rules.md).

## Next element

- **Inline hint**: show the next required element faintly after the cursor ([next element](next-element.md)).
- **Suggest as you type**: open the list of next elements after a space, comma, bracket or closing italics.
- **Status bar**: show the number of problems and the next element.

## Footnotes

- **Write new footnotes in**: a pane below the note (default on desktop), or the note itself ([writing footnotes](writing-footnotes.md)).
- **Return after a footnote**: Enter after the closing full stop, or Escape, returns to the reference.
- **Close the footnote pane when done**: finishing with Enter in the pane also closes it.
- **Keep footnotes at the bottom**: when you leave a note, move its footnotes to the bottom in reading order.
- **Renumber footnotes**: relabel footnotes 1, 2, 3 … when tidying or inserting.
- **Convert inline footnotes**: turn `^[inline]` footnotes into numbered ones when tidying.
- **Keep cross-references in sync**: update `(n X)` when footnotes are added, removed or reordered.

## Headings

- **Heading style**: as written, or the AGLC4 hierarchy I, A, 1, (a), (i) ([headings](headings.md)).
- **AGLC4 level one**: which Markdown heading is level I (automatic, `#` or `##`).

## Legal Core

- **Share citations with Legal Core**: when the Legal Core (Australia) plugin is installed, share the sources your notes cite with its shared store ([Legal Core](legal-core.md)).

## Version history

- **Keep version history**: save versions as you write and before the plugin changes a note ([version history](version-history.md)).
- **History folder**: where the history is kept (default `.aglc-history`, hidden).
- **Minutes between versions**: how often a version is saved while you write.
- **Keep history of**: all notes, or only the notes the plugin works in.
- **Keep every version**: keep every version forever instead of thinning older ones.

## Export and page preview

- **Export folder**: where exports are written; empty to save next to the note ([export](export.md)).
- **Font**: the font of the Word export and the page preview.
- **Body text size** and **Footnote text size**: in points.
- **Keep footnotes on one page**: keep each footnote whole at the bottom of one page.
- **Add a bibliography**: end exports and the page preview with a bibliography ([bibliography](bibliography.md)).
- **Line spacing**: single, 1.5 lines or double.
- **Typographic quotation marks**: export straight quotes as curly quotes.
- **Page numbers**: number the pages of Word exports.
- **Title from file name**: add the note's name as a title when it has no top-level heading.
