# Next element

While you write a citation in a footnote, the plugin shows what AGLC4 requires next.

## The hint

With the cursor at the end of a citation, a faint hint after the cursor names the next required element, for example `‹Law report series›` after `*Mabo v Queensland [No 2]* (1992) 175`. Turn it off with **Inline hint**.

## The popup

After you finish an element (closing italics, a closing bracket, a comma, a number), a list pops up of what can come next, with the required element first. Choosing one inserts it with its placeholder selected, so you can type straight over it: choosing **Year** inserts ` (Year)` with `Year` selected.

The list only ever adds text at the cursor: it never replaces what you have typed. Turn it off with **Suggest as you type**.

## The command

**Suggest next citation element** opens the same list at any time. At the start of an empty footnote it offers a template for each kind of source (a reported case, an Act, a journal article, a book, a web page, and so on), which is a quick way to see what a citation of that kind needs.

## The status bar

The status bar shows the number of problems in the note (`AGLC4 2✕ 1⚠`, or `AGLC4 ✓`) and the next element of the citation at the cursor. Click it to list the problems. Turn it off with **Status bar**.

## Kinds of source

The suggestions follow the structure of each kind of source the plugin knows: reported and unreported cases, medium neutral citations, legislation and Bills, explanatory memoranda, journal articles, books and reports, chapters in edited books, newspaper articles, internet materials, papers, theses and speeches, Hansard, treaties, and Ibid and later references. See [Checking citations](checking.md#what-is-checked) for the elements of each.
