# Commands

Run commands from the command palette (Ctrl/Cmd+P; type "AGLC4" to list them). Give the ones you use most a hotkey in **Settings → Hotkeys**: **Insert footnote** especially.

## Writing

| Command | What it does |
| --- | --- |
| **Insert footnote** | Adds a footnote at the cursor (after any punctuation) and takes you to it ([writing footnotes](writing-footnotes.md)) |
| **Return from footnote to its reference** | Goes back from the footnote at the cursor to its number in the text |
| **Jump between footnote and its reference** | Moves between a footnote and its number within one editor |
| **Suggest next citation element** | Lists what can come next in the citation at the cursor ([next element](next-element.md)) |
| **Move footnotes to the bottom and renumber** | Puts every footnote at the bottom in reading order and relabels them 1, 2, 3 … |

## Checking

| Command | What it does |
| --- | --- |
| **List AGLC4 problems in this note** | Lists the problems, with jump-to (also: click the status bar) ([checking](checking.md)) |
| **Fix all automatically fixable problems** | Applies every available fix in the note |

## Output

| Command | What it does |
| --- | --- |
| **Open page preview** | Shows the pages as Word will print them (also: the book icon) ([page preview](page-preview.md)) |
| **Export to Word with AGLC4 footnotes** | Writes a `.docx` with real footnotes (also: right-click a note) ([export](export.md)) |
| **Export to HTML with AGLC4 footnotes** | Writes a standalone web page with the footnotes at the end |
| **Insert bibliography of cited sources** | Adds the bibliography at the end of the note, where you can edit it ([bibliography](bibliography.md)) |
| **Import Word document** | Turns a `.docx` into a note with its footnotes (also: right-click a `.docx`) ([import](import.md)) |

## Paragraph prompts

| Command | What it does |
| --- | --- |
| **Choose paragraph prompts for this note** | Turns on prompts for a kind of essay or problem answer (IRAC, ILAC, HIRAC, MIRAT, critical analysis, "discuss", or your own), or off ([paragraph prompts](paragraph-prompts.md)) |
| **New legal essay or problem answer** | Creates a note with the outline of the kind you choose, and its prompts on |
| **Copy a prompt set to edit as your own** | Copies a set of prompts to a note, where you can edit it as your own set |

## Version history

| Command | What it does |
| --- | --- |
| **Show version history** | Opens the history of the active note (also: the clock icon, or right-click a note) ([version history](version-history.md)) |
| **Save a named version of this note** | Names the current version, such as "Submitted"; named versions are kept forever |
| **Restore a deleted note from version history** | Brings back a deleted note as last saved |

## Notes and getting started

| Command | What it does |
| --- | --- |
| **Turn AGLC4 on for this note** | Marks the note as an assignment note ([notes](notes.md)) |
| **Turn AGLC4 off for this note** | Leaves the note alone: no checking or automatic changes |
| **Create example essay** | Adds an example essay to try the plugin on ([getting started](getting-started.md)) |
